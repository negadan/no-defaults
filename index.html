What gets cut

Each of these is a library default. The skills make the agent notice it, name the version that belongs to your subject, and build that instead.

DefaultDecided
  • Centered hero with a primary and a ghost buttonInsteadAn opening that shows the subject itself
  • Three icon cards in a rowInsteadA layout taken from the subject's own spatial metaphor
  • Indigo-to-purple gradient on whiteInsteadFour to six colors taken from the subject's world
  • System font at one size and one weightInsteadA real type pairing with a set scale
  • A spinner, "No data" and a red "Error" toastInsteadLoading, empty and error states that tell people what to do next
  • Everything fades in, or nothing moves at allInsteadWeighted motion only on the gestures that matter
  • "Manage your workflow efficiently"InsteadCopy that names what the user actually controls

PS> Copy-Item -Recurse -Force .\skills\* "$HOME\.claude\skills\"
